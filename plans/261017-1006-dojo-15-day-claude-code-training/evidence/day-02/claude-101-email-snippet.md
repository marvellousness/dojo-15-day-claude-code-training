# Claude 101 — short version for the daily report email

**Claude 101** (Claude Academy, 13 lessons + quiz): completed — badge: https://academy.claude.com/badges/60b6e887-8a60-479b-a21f-423bb97e1915

Key learnings:
- **Prompt in three parts:** set the stage (role, goal, context), define the task, specify rules (format, tone, examples). Iterate from there; start a new chat when a thread goes off track.
- **Fixing weak answers:** add context when it's generic, state the length and show the format, and verify confident-sounding facts (ask for sources, use web search).
- **Evals before delegating:** test Claude on past work where I already know the answer, refine, and only delegate once the results match.
- **Three ways to work in the desktop app:** Chat (turn by turn), Cowork (hand off a multi-step task, even on a schedule), Code tab (build software).
- **Organising context:** Projects hold knowledge and instructions, Skills hold repeatable procedures ("projects store knowledge, skills perform tasks"), and Connectors (MCP) let Claude read and act in my tools. Claude only sees what I can see.
- **Outputs:** artifacts (designs, decks, docs, tools you keep editing and share by link) vs file creation (downloadable xlsx/pptx/docx/pdf). Research produces cited, multi-source reports in minutes.

Takeaway for my work: brief Claude like a coworker with the context only I have, check its output against known answers before trusting it with a task, and use CLAUDE.md, skills and MCP in Claude Code the same way projects, skills and connectors work in claude.ai.
